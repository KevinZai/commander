3 · Escalation Rules

  • Main thread is fixed at session start — Claude cannot silently hot-swap the running session's model. Escalate deep-reasoning work explicitly: /model claude-fable-5. Main thread stays Opus 4.8 until you escalate.
  • Subagents auto-route by complexity — dispatcher picks Haiku → Sonnet → Opus → Fable per delegated task, silently, based on a reasoning-complexity score.
  • Never switch models mid-session — spawn a subagent on the target model instead of changing the main thread's model repeatedly.
  • Fleet-scale work → /ccc-fleet — 3-tier orchestration: Fable conducts Opus leads Sonnet workers, reserved for fleet/worktree-parallel work only.
