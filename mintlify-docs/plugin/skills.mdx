CC Commander v7.2.0 ships **80 plugin skills** across nine groups. All skills are **core free forever** — no caps, no call limits, no tier gating. All skills appear as plain `/ccc-*` in autocomplete — no namespace prefix required. Run `/ccc-browse` in Desktop for the live filterable catalog.

## Group 1 — 13 /ccc-* Specialist Workflows

Click-first workflows. Each opens an interactive picker (AskUserQuestion native chips) — no flags or arguments needed.

| Skill | Trigger | What it does |
|-------|---------|--------------|
| `/ccc` | `/ccc` or "open commander" | Main hub — detects project context, routes to the right specialist workflow via nested picker |
| `/ccc-start` | `/ccc-start` or "get started with ccc" | First-run onboarding — creates plan file, explains the plugin, surfaces your first win |
| `/ccc-browse` | `/ccc-browse` or "browse skills" | Searchable catalog of all 467+ skills and 22 agents — filter by domain, keyword, or tier |
| `/ccc-plan` | `/ccc-plan` or "plan a feature" | Spec-first planning — 5-question interview → `tasks/spec-YYYYMMDD.md` → ready to build |
| `/ccc-build` | `/ccc-build` or "build something" | Guided build wizard — web app, API, CLI, or mobile. Dispatches the builder agent with spec |
| `/ccc-review` | `/ccc-review` or "review my code" | Branch audit — diff review, security pass, performance check, or full x-ray. Uses reviewer agent |
| `/ccc-ship` | `/ccc-ship` or "ship this" | Pre-flight checks + release + deploy. 22-point gate: TypeScript, tests, secrets, env vars |
| `/ccc-design` | `/ccc-design` or "design this" | UI/UX workflow — routes to ccc-design domain (39 skills: animations, systems, accessibility) |
| `/ccc-learn` | `/ccc-learn` or "teach me" | Skill discovery across all 11 CCC domains — explains what's available and when to use each |
| `/ccc-xray` | `/ccc-xray` or "audit my project" | Project health scorecard — surfaces issues as fix chips you can click to resolve |
| `/ccc-linear` | `/ccc-linear` or "show my board" | Linear board integration — view issues, pick one to build, create new issues, sync status |
| `/ccc-fleet` | `/ccc-fleet` or "run in parallel" | Multi-agent orchestration — launch, route, monitor, and kill parallel agent workers |
| `/ccc-connect` | `/ccc-connect` or "connect my tools" | Opt-in MCP connector — Notion, Zapier, Supabase, Slack, Google Drive, Figma, and more |

## Group 2 — 11 ccc-* Domain Routers

Load ONE domain skill to get an entire specialty. Each router matches your intent and dispatches to the right sub-skill. (The Commander Cockpit's Browse tab additionally displays a **14-domain taxonomy** for filtering — it splits `commands`, `general`, and a few finer-grained buckets out of these same 11 routers for browsing purposes. The 11 routers below are the canonical CCC domains.)

| Skill | Skills Inside | What it covers |
|-------|--------------|----------------|
| `ccc-design` | 39 | UI/UX, animations, visual effects, design systems, accessibility, landing pages |
| `ccc-marketing` | 45 | CRO, email campaigns, ads, social content, growth, sales copy |
| `ccc-saas` | 21 | Auth, billing, multi-tenant DB, API patterns, frontend stack, SaaS metrics |
| `ccc-devops` | 21 | CI/CD, Docker, AWS, Terraform, monitoring, zero-downtime deploys |
| `ccc-seo` | 20 | Technical SEO, Core Web Vitals, schema markup, AI search, programmatic SEO |
| `ccc-testing` | 15 | TDD, E2E (Playwright), visual testing, load testing, coverage audits |
| `ccc-data` | 8 | SQL, ETL pipelines, data warehousing, analytics, visualization, ML ops |
| `ccc-security` | 8 | OWASP audits, pen testing, secrets management, supply chain, threat modeling |
| `ccc-research` | 8 | Deep research, competitive analysis, literature review, data synthesis |
| `ccc-mobile` | 8 | React Native, Expo, iOS, Android, Flutter, app store optimization |
| `ccc-makeover` | 3 | `/xray` project audit + `/makeover` design swarm + report generation |

> **Note:** The domain routers for `ccc-design`, `ccc-fleet`, and `ccc-linear` are also exposed as `/ccc-design`, `/ccc-fleet`, and `/ccc-linear` specialist workflows (Group 1). They appear in both groups because they serve double duty — as click-first entry points and as loadable domain packs.

Adapted from the superpowers vendor with attribution. Both are core free forever.

## Group 8 — Orchestrator / Executor Skills

The plan/execute split: high-reasoning models write goal files and verify; execution runtimes do the token-heavy implementation work.

| Skill | Trigger | What it does |
|-------|---------|--------------|
| `/ccc-orchestrate` | `/ccc-orchestrate` or "orchestrate this", "goal file executor" | Cross-runtime Orchestrator/Executor — Fable/Opus writes a Skill.md-style goal file, GPT-5.5 via `codex` or Sonnet executes, orchestrator verifies acceptance criteria |
| `/ccc-adopt` | `/ccc-adopt` or "adopt commander", "add ccc doctrine" | Bring the Orchestrator/Executor doctrine into an existing project — merge a marked `CLAUDE.md` block without clobbering local rules |
| `/ccc-relay` | `/ccc-relay` or "cross-session loop", "spec build review chain" | Cross-session loop chaining — chains independent gated spec → build → review sessions with a durable handoff baton; merge stays human-approved (v6.7.0) |
| `/ccc-smb-ops` | `/ccc-smb-ops` or "small business ops", "invoicing", "cash flow" | Small-business-operations domain (router + 6 sub-skills): invoicing/AR, cash-flow forecast, expense tracking, payroll planning, CRM hygiene, weekly owner brief (v6.7.0) |
| `/ccc-broadcast` | `/ccc-broadcast` or "status updates", "tell the team when it ships" | Outbound status relay — pushes scrubbed build/deploy/CI/task/cost signals to team chat or email via `/ccc-connect`; the outbound counterpart to `/ccc-nightwatch` (v6.7.1) |
| `/ccc-spawn` | `/ccc-spawn` or "spawn a session", "spin this off" | Click-first spawn hub — spin isolated work into its own session (spawn_task chip in Cowork, `/spawn` peer in CLI); routes to `/ccc-fleet` or `/ccc-relay` (v6.7.2) |
| `/ccc-prompt-fix` | `/ccc-prompt-fix` or "fix my prompt", "sharpen this prompt" | Auto prompt fixer — diagnoses a prompt against the 6 quality patterns, returns a tighter rewrite with the reasoning, suggests the matching library prompt (v6.7.3) |

## Group 9 — Decks

Self-contained artifacts that turn data CCC already logs into a page. Every deck carries a shared decks switcher strip so you can jump between them.

| Skill | Trigger | What it does |
|-------|---------|--------------|
| `/ccc-usage` | `/ccc-usage` or "what am I spending", "show my savings" | Usage & Cost deck — burn, estimated savings vs. an all-Opus baseline (honest, not a bill), saved/day + cost/day trends, cost-by-app split. See [`/ccc-usage`](/plugin/skills/ccc-usage). |
| `/ccc-safety` | `/ccc-safety` or "what did commander block", "safety report" | Safety deck — blocked/auto-fixed/approved action outcomes, redacted tool-failure hotspots. See [`/ccc-safety`](/plugin/skills/ccc-safety). |
