CC Commander is **core free forever**. All 81 plugin skills, 22 specialist sub-agents, 23 lifecycle hooks (43 handlers), 2 credential-free bundled MCP servers, 16 opt-in connectors, and the full 467+ ecosystem skill catalog are free — no credit card, no license check, no feature gating, no caps on the plugin.

## What's free forever

- ✅ All **81 plugin skills** — every `/ccc-*` workflow, domain router, channel/CI skill
- ✅ All **22 specialist sub-agent personas** (architect, reviewer, builder, debugger, security-auditor, designer, qa-engineer, devops, data-analyst, product-manager, content-strategist, technical-writer, fleet-worker, performance-engineer, researcher, plus 7 language-specific reviewers)
- ✅ All **23 lifecycle hooks** with **43 handlers**
- ✅ **2 credential-free bundled MCP servers** (context7 + sequential-thinking)
- ✅ **16 opt-in MCP connectors** via `/ccc-connect`
- ✅ **467+ ecosystem skills** across 11 CCC domains
- ✅ Community support via [GitHub Discussions](https://github.com/KevinZai/commander/discussions)
- ✅ **100 hosted MCP calls/month** — the hosted MCP is live at `mcp.commanderplugin.com`; the 100-call cap is an anti-abuse cap, not a paywall

The plugin code is MIT-licensed and fork-able. There are no license keys and no tier gating anywhere in the plugin.

## How it stays free (transparency)

Four sustainability levers — none of which require you to pay:

1. **Kevin's consulting practice** (primary) — the plugin is a trust engine, not a funnel
2. **Transparent affiliate links** in `/ccc-connect` (Supabase, Vercel, Neon, etc.) — see [Affiliate Disclosure](/affiliate-disclosure)
3. **Optional Pro community** — a paid Discord for advanced patterns and direct access; the plugin stays free
4. **[GitHub Sponsors](https://github.com/sponsors/KevinZai)** — gratitude tiers, not feature unlocks

## What about a Pro tier?

A **hosted-infrastructure Pro tier is planned later** — it will cover hosted services that cost real money to run (hosted MCP, cross-machine state sync), not content. **All content stays free forever:** skills, agents, hooks, and connectors will never move behind a paywall. Pricing has not been announced.

The hosted MCP service is live at `mcp.commanderplugin.com` and remains free for everyone with a 100-call/month anti-abuse cap.

## What we will never do

- ❌ Paywall skills, agents, hooks, or any other content — content stays free forever
- ❌ License-key gating on the plugin core (impossible — it's open-source)
- ❌ Telemetry-driven nag popups or upsells
- ❌ Time-limited trials that degrade to a worse state
- ❌ Sell your data — anonymous telemetry is used for aggregate feature prioritization only, never sold or shared. Opt out anytime with `CCC_TELEMETRY=0`

## Affiliate income (separate)

CC Commander earns affiliate revenue from `/ccc-connect` connectors (Vercel, Supabase, Neon partner programs). These are transparently disclosed in `commander/cowork-plugin/CONNECTORS.md`. They don't affect what you pay — the vendor pays *us* a referral fee for sending qualified leads. You always see the full URL before clicking.

## Sponsor the project

If you want to support CC Commander directly: [GitHub Sponsors](https://github.com/sponsors/KevinZai). Sponsorships are gratitude tiers, not feature unlocks — nothing in the plugin is gated behind sponsorship.
