CC Commander is a paid product with three plans. **Free during launch** for early adopters while we ship the hosted infrastructure. After we hit a stable user base, Starter pricing or caps may change.

| Plan | Price | Best for |
|------|-------|----------|
| **Starter** | $0 *(early access — limited time)* | Anyone evaluating, OSS contributors |
| **Pro** | $19/mo · $190/yr | Daily users who want unlimited cloud + premium |
| **Lifetime** | $299 one-time *(first 100 — then $499)* | Commitment makers who'd rather not subscribe |

## What's in Starter (free during launch)

The MIT-licensed plugin core. Everything below is free **during early access** — once we stabilize the paid tier infrastructure, Starter pricing or caps may change for new users. **Anyone who installs Starter today keeps current access while we sort out the steady-state.** The plugin code itself stays MIT-licensed and fork-able regardless.

- ✅ All **60 plugin skills** — every `/ccc-*` workflow, domain router, channel/CI skill
- ✅ All **22 specialist sub-agent personas** (architect, reviewer, builder, debugger, security-auditor, designer, qa-engineer, devops, data-analyst, product-manager, content-strategist, technical-writer, fleet-worker, performance-engineer, researcher, plus 7 language-specific reviewers)
- ✅ All **9 lifecycle hooks** with **24 handlers** (SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, Stop, Notification, PreCompact, SubagentStop, PermissionRequest)
- ✅ **2 credential-free bundled MCP servers** (context7 + sequential-thinking)
- ✅ **16 opt-in MCP connectors** via `/ccc-connect` (Notion, Slack, GitHub, Supabase, Figma, Linear, Vercel, Neon, Fly.io, Upstash, Sentry, Stripe, Browserbase, Postgres, Cloudflare, Redis)
- ✅ **502+ ecosystem skills** across 11 CCC domains
- ✅ Community support via [GitHub Discussions](https://github.com/KevinZai/commander/discussions)
- ✅ **100 hosted MCP calls/month** (when CC Cloud ships) — anti-abuse cap

## What's in Pro

Pro is **paid hosted services + curation**. The plugin code itself is the same — Pro adds:

- 🚀 **Unlimited hosted MCP calls** — no monthly cap, batch-friendly latency
- 📦 **Premium skill packs** — 8-10 advanced workflow templates curated and maintained:
  - Enterprise SSO patterns (SAML, OIDC, Okta/Auth0/Azure AD)
  - Multi-tenant SaaS templates (row-level security, billing, invitations)
  - Complex DB migration patterns (zero-downtime, schema versioning, backfills)
  - Advanced observability (OTel, Honeycomb, distributed tracing)
  - Chaos-engineering playbooks
  - Plus more shipping monthly
- 📧 **Priority email support** — 24-hour response SLA on bugs and questions
- ⚡ **Early access** — 1-week head start on new skills, hooks, agents before they ship to Starter
- 🔄 **Cross-machine state sync** (when CC Cloud ships) — `~/.claude/commander/` synced across your laptops
- 💬 **Pro Discord** — private channel with Kevin + other Pro users (launches at 200 GitHub stars)

## What's in Lifetime

Everything in Pro, **forever**, for a single one-time payment.

- 🏆 **Founding member** — early supporters get a permanent badge in Pro Discord
- 🔒 **Locked-in pricing** — your $299 is the only thing you ever pay; future Pro price hikes don't apply
- 📅 **All future Pro features included** — premium skill packs as they launch, sync, support, all of it
- ⏳ **Limited launch pricing** — first 100 lifetime sales at $299. After that, Lifetime moves to $499.

## Why we charge for Pro (transparency)

Hosted MCP costs real money to run — Fly.io machines, Upstash Redis, Supabase database, bandwidth. Premium skill packs take real time to research and curate (10-20 hours per pack). Priority support is real engineering time.

Pro pricing pays for these things directly. Starter is **free during launch** because the plugin code is git-clonable — paywalling it would be both impossible and counter-productive while we're building the community. As we scale, Starter may move to capped free (e.g., reduced hosted MCP calls) while Pro remains unlimited.

## What we will never do

- ❌ Retroactively paywall **existing** Starter features that shipped today (skills/agents/hooks)
- ❌ License-key gating on the plugin core (impossible — it's open-source)
- ❌ Telemetry-driven nag popups
- ❌ Time-limited trials that degrade to a worse state
- ❌ Sell your data — there is no telemetry, period

## How to upgrade

1. Visit [cc-commander.com/pricing](https://cc-commander.com/pricing)
2. Pick monthly, yearly, or lifetime
3. Lemon Squeezy checkout (handles VAT/sales-tax globally as Merchant of Record)
4. Receive license key via email
5. Set `CCC_PRO_LICENSE_KEY` env var or save to `~/.claude/commander/license.json`
6. Pro features activate on next session

## Refunds

14-day money-back guarantee on monthly and yearly. Lifetime: 30-day refund window (since you're committing for the long haul).

## Affiliate income (separate)

CC Commander also earns affiliate revenue from `/ccc-connect` connectors (Vercel, Supabase, Neon partner programs). These are transparently disclosed in `commander/cowork-plugin/CONNECTORS.md`. They don't affect what you pay — Vercel pays *us* a referral fee for sending qualified leads. You always see the full URL before clicking.

## Sponsor independently of pricing

If you don't need Pro features but want to support the project: [GitHub Sponsors](https://github.com/sponsors/KevinZai) has Coffee ($5/mo), Server ($19/mo), and Patron ($99/mo) tiers. These are gratitude tiers, not feature unlocks — Sponsors get name credit + Pro Discord access without buying Pro.
