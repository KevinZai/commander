# LinkedIn cross-post (DRAFT, not scheduled; Day 2)

I just shipped CC Commander v8.1.0, an open-source PM layer for Claude Code, Cowork Desktop and Codex.

The problem: AI coding agents are powerful but leave you managing prompts instead of projects.

What it does:
- `/ccc` gives a click-first menu: Build, Review, Ship
- 84 skills and 22 specialist agents, with a planner coordinating focused builders and reviewers
- Workflows where every finding is adversarially verified before it reaches you
- Works in Claude Code Desktop, the CLI, Codex and MCP-capable IDEs

Core is free and MIT licensed. One caveat: Codex lacks some Claude hook events, so a few hooks are remapped.

Install: /plugin install commander --marketplace KevinZai/commander
Repo: https://github.com/KevinZai/commander
