## What this changes for you

- **Same price** — you pay exactly what you'd pay going direct
- **No hidden markup** — affiliate commissions come from the vendor's budget, not yours
- **Opt-out always available** — every service above can be reached via the direct URL in the table
- **We only recommend what we use** — no services are added to `/ccc-connect` without Kevin using them first

## How to spot affiliate links

In the Cowork Desktop UI, `/ccc-connect` tags every affiliate-eligible connector with `[aff]`
next to the service name.

In these docs, we use a `<Note>` callout above any affiliate link:

<Note type="info">
  Affiliate link — we may earn a commission if you sign up. Same price either way.
</Note>

## Revenue model

CC Commander sustains itself through four independent revenue streams so no single one
dominates decisions:

1. **Transparent affiliate links** in `/ccc-connect` (this page)
2. **Kevin's consulting practice** — the plugin is a trust-building engine, not a funnel
3. **Optional Pro community** — $49/mo Discord for advanced patterns and direct access
4. **GitHub Sponsors** — one-time or monthly support

No feature is gated behind payment. All 77+ plugin skills, 22 specialist agents,
23 lifecycle hooks, and 2 bundled MCP servers are core free forever.
