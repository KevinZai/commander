## v7.0.0 — Commander Cockpit Product Release

The Commander Cockpit becomes a real product: the commanderplugin.com terminal brand end-to-end, a browse experience built for finding a skill fast, a genuinely usable prompt enhancer, and — under the hood — agent telemetry that reports real numbers or an honest "—", never a fabricated zero.

### Filterable skill browser

Browse is now a scannable skill LIST with a **rows / tiles toggle** (persisted) instead of a wall of one-skill "domains". Compact domain-filter chips (`all · 533`, `marketing · 46` … `general · 257`) plus real-time filter on name, purpose, or domain; a whole-row click copies the command.

### Multi-select prompt enhancer

The enhance tab is **11 improvement strategies as multi-select chips** (outcome, self-check, reference, target, deliverable, format, role, constraints, context, plan-first, example) with a ✓ "already covered" hint, `select all` / `what's missing` / `clear`, and a **GO** button that appends the chosen directives to your prompt to copy into Claude Code.

### Real per-agent token & cost telemetry

`hooks/lib/transcript-usage.mjs` recovers real input/output tokens and duration from the transcript each `SubagentStop` points to, keyed by `message.id` so streaming rows are never double-counted. `cache_read` tokens are recovered and priced into cost (≈0.1× rate) without inflating the token headline.

<Note>
  **Honest telemetry contract:** when token data was never captured, tiles render `— unavailable` and per-agent tokens/cost render `— tok` / `$—` rather than a measured-looking `0` / `$0.00`.
</Note>

### Brand and taxonomy

Cockpit, Mission Control, dashboard, and both websites are unified on the real commanderplugin.com palette (coral `#FF6B47` / tan / near-black, Inter + JetBrains Mono). The skill taxonomy collapses plugin `/ccc-*` commands into one **commands** front-door group, routes ungrouped ecosystem skills to an honest **general** bucket, and groups domain routers as `ccc-X` — **14 real display domains**, no misleading "core" catch-all. This is a display taxonomy inside the Cockpit; it's distinct from the 11 canonical CCC domain routers documented in [Plugin Skills](/plugin/skills).

## v7.1.0 — Cockpit Tools Tab

A 7th Cockpit tab turns it into an ecosystem launcher, surfacing everything that pairs with Commander as clickable cards:

- **Commander surfaces** to open — `/ccc-mission-control`, `/ccc-fleet-viz`, `/ccc-xray`, `/ccc-doctor`.
- **Companion apps** — the best MIT-licensed tools to install alongside Commander (Nimbalyst, Claude Code Usage Monitor, Claude Control, Sniffly, tmux session manager), licenses verified via the GitHub API. These are links (copied to the clipboard, never an external `href`) — per the "interop, don't rebuild" principle. AGPL tools are deliberately excluded.
- **Artifact recipes** — copy-a-prompt cards (before/after sales arcade, standup/status board, PR walkthrough) that have Claude build a live dashboard on demand.

Self-contained and CSP-safe; companion URLs never leak into an external `href`.

## v7.2.0 — Commander Decks Switcher + 2 New Decks

### Commander decks switcher

A shared top strip (`lib/deck-switcher.js`) now rides every Commander artifact — Cockpit, Mission Control, and the two new decks below — listing all of them as chips with the current one highlighted, so you can always see every artifact exists and jump between them. Interactive (copy-to-open) on the Cockpit; static (command shown) on the no-`<script>` snapshot decks. One shared module, theme-safe via brand tokens.

### `/ccc-usage` — Usage & Cost deck

A self-contained artifact built from data CCC already logs: cumulative **estimated savings** ("$X saved across N dispatches", honestly labelled as an estimate vs. an all-Opus baseline — never presented as a bill), saved/day and cost/day trends, and a **cost-by-app** split (Claude vs. Codex). See [`/ccc-usage`](/plugin/skills/ccc-usage) for the full reference.

### `/ccc-safety` — Safety deck

Dangerous actions **blocked**, **auto-fixed**, and approved (from `permission-gate.jsonl`), plus a Sniffly-style **tool-failure hotspots** breakdown — top tools plus normalized, secret-redacted error signatures from `tool-failures.jsonl`. See [`/ccc-safety`](/plugin/skills/ccc-safety) for the full reference.

### Fixed

Emoji mojibake in the snapshot artifacts — Mission Control, Usage, and Safety fragments now declare `<meta charset="utf-8">` (the Cockpit already did), so emoji render correctly when served standalone, not just inside the Artifact wrapper.

## v7.3.0 — Update Self-Detection + Cockpit Prompts Tab

### Commander finally notices its own updates

A **SessionStart hook** (`hooks/update-nudge.js`, 24h-cached, offline-silent) compares your installed version against GitHub `main` and, when a newer release exists, tells you the exact fix — marketplace update → plugin update → restart. Third-party plugin marketplaces have auto-update **off by default**, so nothing else was ever going to tell you.

### `/ccc-update` — 81st plugin skill

The click-first counterpart to the ambient nudge: detect installed vs. latest, run the two update commands (with your confirmation), remind you to restart, and verify the version + hooks are actually live afterward. See [`/ccc-update`](/plugin/skills/ccc-update) for the full reference. `/ccc-doctor` also now diagnoses every stale-install layer — a marketplace clone behind `main`, old `cache/<version>` directories, stale Desktop inline copies, catalog-cache age — and offers, with consent, to enable marketplace auto-update.

### Cockpit "Prompts" tab

An 8th Cockpit tab: a navigable, searchable prompt browser across four sources — the Claude Code docs prompt library (52 prompts, with attribution + a refresh script), the CCC library (52 field-tested prompts + 6 quality patterns + course modules), the repo's 36 prompt templates, and a ReadyIQ agent showcase. Filter by source, SDLC phase, or category; copy any prompt, or send it straight into the Enhance tab with one click.

### Deck freshness honesty

Every deck now shows "**Data through** &lt;timestamp&gt;" (the newest source row) beside the render stamp, and warns when telemetry is more than 24 hours stale ("hooks may not be running — run `/ccc-doctor`"). Rebuilding a deck from months-old data can no longer masquerade as fresh.

### Proactive moments, made real

The suggestion engine now surfaces update-available and stale-telemetry signals, writes real entries into Mission Control's Suggestions panel (previously it had no producer and sat permanently empty), and keys all its state per-project — suggestions and dismissals no longer leak between repositories. Safety's "auto-fixed" metric is now real too: the permission gate logs `approved-autofix` when an autofix write is actually approved.

### Fixed: the Codex mirror actually works now

The translator had been rewriting every hook and skill to `${CODEX_PLUGIN_ROOT}` — a variable Codex never sets (it provides `PLUGIN_ROOT`/`PLUGIN_DATA` and honors `CLAUDE_PLUGIN_ROOT` for compatibility) — so **every mirrored hook was dead on every Codex install to date**. Also fixed: 4 supported events were wrongly dropped (`SubagentStart`/`SubagentStop`, `PreCompact`/`PostCompact` — the mirror now carries 10 events, was 6), `async` handlers (which Codex silently skips) are stripped, and the docs now cover Codex's hook trust gate. See [Codex Compatibility](/features/codex-compatibility) for the full writeup.

<Note>
  Also fixed: `/ccc-usage` now triggers the canonical metrics recompute instead of reading a stale rollup and honestly labels the savings hero when `savings.json` isn't being fed; the Cockpit builder now ships **inside** the plugin so marketplace installs can regenerate it; and `check-version-parity` now gates 9 version surfaces (was 4).
</Note>
