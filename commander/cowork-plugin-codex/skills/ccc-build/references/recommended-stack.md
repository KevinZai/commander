# /ccc-build — recommended stack by template

Shown after the progress card (SKILL.md step 5). Show only the block for the chosen template, and always keep the disclosure line with it.

> 💰 Affiliate-supported: some links below earn CC Commander a small commission at no cost to you. [Disclosure](https://docs.commanderplugin.com/affiliate-disclosure)

## Web app / SaaS

- 📦 [Supabase](https://supabase.com?utm_source=ccc&utm_medium=plugin&utm_campaign=ccc-build&utm_content=supabase-saas-scaffold) — Postgres + auth + storage. The free tier covers most projects.
- 🌐 [Vercel](https://vercel.com?utm_source=ccc&utm_medium=plugin&utm_campaign=ccc-build&utm_content=vercel-deploy-saas) — Next.js hosting with an ample free tier.
- 🔄 [Upstash](https://upstash.com?utm_source=ccc&utm_medium=plugin&utm_campaign=ccc-build&utm_content=upstash-redis-queue) — Serverless Redis/Kafka, pay per use.

## API / backend

- 📦 [Supabase](https://supabase.com?utm_source=ccc&utm_medium=plugin&utm_campaign=ccc-build&utm_content=supabase-api-postgres) — Postgres + auto-generated REST API.
- 🌐 [Vercel](https://vercel.com?utm_source=ccc&utm_medium=plugin&utm_campaign=ccc-build&utm_content=vercel-deploy-api) — Serverless functions with easy scaling.
- 🔄 [Upstash](https://upstash.com?utm_source=ccc&utm_medium=plugin&utm_campaign=ccc-build&utm_content=upstash-queue-tasks) — Job queue and rate limiting for async workloads.

## CLI tool

- 📦 [npm](https://www.npmjs.com) — the package registry, if the user later chooses to publish (publishing is a separate, authorized step).
- 🚀 [GitHub Releases](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases) — host binaries and downloads.

## Rules

- Recommendations are suggestions. Do not install a service, create an account, or add a dependency for it unless the user asks.
- `/ccc-connect` installs connectors and shows the same disclosure.
