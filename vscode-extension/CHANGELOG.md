# Changelog

## [0.1.0] - 2026-05-14

### Added
- Initial release of CC Commander VS Code extension
- Sidebar panel with 22 specialist agents (Architect, Builder, Designer, Security Auditor, etc.)
- Sidebar panel with 60 plugin skills (ccc-build, ccc-design, ccc-deploy, ccc-fleet, etc.)
- Quick Actions panel with links to Command Hub, Skill Picker, Agent Picker, and documentation
- Skill Picker command via Ctrl+Shift+Alt+S (or Cmd+Shift+Alt+S on Mac)
- Agent Picker for selecting specialist agents
- Command Hub launcher (/ccc)
- Link to CC Commander Bible documentation
- Claude Code Desktop installer prompt
- Configuration option to open in Desktop vs inline editor
- Free tier — no authentication required
- MIT license

### Features
- 22 specialist agents with effort levels and model assignments
- 60 plugin skills with descriptions and command references
- VS Code sidebar integration with three panels
- Quick-pick menus for both skills and agents
- Fallback to inline editor prompt insertion if Desktop not available
- Full TypeScript strict mode compilation
- Ready for VS Code Marketplace
