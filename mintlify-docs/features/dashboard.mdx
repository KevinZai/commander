CC Commander answers "what is the system doing right now, and what has it been doing recently?" two ways: **self-contained artifacts published inside your Claude Code session** (the current, primary surface, current as of v7.2.0), and a **localhost browser dashboard** for raw session-file inspection outside any session.

## Commander Cockpit, Mission Control & Decks (in-session artifacts)

<Note>
  **Current as of v7.2.0.** These are self-contained HTML artifacts — no server, no build step — published via the Artifact tool from inside a Claude Code session. Every one of them carries a shared **Commander decks** switcher strip so you can jump between them.
</Note>

<Warning>
  Publishing any of these artifacts uploads the rendered page to your private claude.ai artifact URL — private to your account, but it leaves the machine. Every deck always asks before publishing and never publishes automatically. The Safety and Usage decks redact secrets-shaped strings and label cost figures as estimates, not bills.
</Warning>

## Local session inspector (browser, port 4690)

CC Commander also ships a separate, standalone localhost browser dashboard for raw session-file inspection — useful outside any active Claude Code session.

```bash
ccc --dashboard
```

Opens `http://localhost:4690` in your default browser. The server is local-only — no external network connections.

**What it shows:**
- Active session metadata (model, cost, context %, start time)
- Recent session history from `~/.claude/commander/sessions/`
- Fleet agent completion log from `notifications.jsonl`
- Skill usage frequency from knowledge captures

**Architecture:** tiny Node.js `http` server, no framework; vanilla HTML/CSS/JS frontend, no build step; reads `~/.claude/commander/` on request; localhost-only, no auth needed; zero dependencies (ships with Node.js). A React/Vite prototype exists in `dashboard/_archive/` as a UI reference only — it rendered demo data and was retired.

## Fleet view

[`/ccc-fleet-viz`](/plugin/skills/ccc-fleet-viz) is complementary to both surfaces above — it renders in-session ASCII/Mermaid fleet activity without needing either dashboard open.
