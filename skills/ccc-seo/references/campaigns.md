# ccc-seo campaigns

Multi-step SEO jobs. Run one sub-skill at a time, in order, and carry each step's output into the next. Every campaign starts from `seo-context.md` in the project root (written by `seo-context`).

## Full SEO audit

1. `seo-context` — capture current state
2. `seo-optimizer` — technical audit
3. `site-architecture` — structure review
4. `backlink-audit` — link profile
5. `search-console` — performance data
6. `seo-dashboard` — unified report
7. Deliver the findings and a prioritized action plan

## Content-led SEO campaign

1. `seo-context` — domain and competitor analysis
2. `content-cluster` — topic cluster strategy
3. `seo-content-brief` — a brief for each page
4. `blog-engine` — set up the publishing system
5. `social-integration` — sharing optimization
6. `analytics-conversion` — tracking setup
7. Monitor with `search-console` and `serp-analyzer`

## AI search optimization

1. `seo-context` — current AI search presence
2. `ai-seo` — optimize for LLM citations
3. `aaio` — robots.txt AI bot policy, markdown twins, structured data
4. `seo-optimizer` — technical foundation
5. Verify with manual queries in the AI search surfaces the user targets, and record which pages are cited

## Programmatic SEO at scale

1. `seo-context` — target keywords and competitors
2. `bulk-page-generator` — template design and data sourcing
3. `site-architecture` — URL structure and internal linking
4. `seo-optimizer` — technical SEO for the generated pages
5. `analytics-conversion` — tracking at scale
