## Get your license key

After purchasing Pro on the [pricing page](https://cc-commander.com/pricing), Lemon Squeezy sends a confirmation email with your license key. The key looks like this:

```
XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX
```

Keep this key somewhere safe. You can retrieve it anytime from your [customer portal](https://app.lemonsqueezy.com/my-orders).

---

## Activate

Choose either method. Both work identically.

### Method 1 — Environment variable (recommended for CI/scripted setups)

Set `CCC_PRO_LICENSE_KEY` before launching Claude Code:

```bash
export CCC_PRO_LICENSE_KEY="your-key-here"
```

Add it to your shell profile (`~/.zshrc`, `~/.bashrc`) to persist across sessions:

```bash
echo 'export CCC_PRO_LICENSE_KEY="your-key-here"' >> ~/.zshrc
source ~/.zshrc
```

### Method 2 — License file (recommended for desktop use)

Create the file `~/.claude/commander/license.json`:

```json
{
  "license_key": "your-key-here"
}
```

That's it. No restart required — the plugin reads this file at the start of each session.

```bash
# One-liner to create the file:
mkdir -p ~/.claude/commander && cat > ~/.claude/commander/license.json <<'EOF'
{
  "license_key": "your-key-here"
}
EOF
```

## Verify activation

Run `/ccc-doctor` in any Claude Code session. The **License** row shows your current tier:

```
License  ✅ Pro (monthly) — validated 2 hours ago
```

If you see `Starter`, the key hasn't been picked up yet. See [Troubleshooting](#troubleshooting) below.

---

## How validation works

CC Commander validates your key against the Lemon Squeezy API once, then caches the result for **24 hours** in `~/.claude/commander/license-cache.json`. This means:

- No network call on every session start — validation is instant after the first check.
- If the Lemon Squeezy API is temporarily unavailable, your cached Pro status is preserved.
- The cache auto-refreshes every 24 hours in the background.

## Troubleshooting

<AccordionGroup>
  <Accordion title="License tier still shows Starter after activation">
    The license cache may need a manual refresh. Delete it and restart your session:

    ```bash
    rm ~/.claude/commander/license-cache.json
    ```

    Then open a new Claude Code session — validation runs automatically.
  </Accordion>

  <Accordion title="'Invalid license' in /ccc-doctor output">
    This means the key was rejected by Lemon Squeezy. Common causes:

    - **Typo in the key** — copy-paste directly from your email, don't retype.
    - **Key used on too many machines** — Pro allows 3 activations. Check your [customer portal](https://app.lemonsqueezy.com/my-orders) to deactivate an old machine.
    - **Subscription lapsed** — check your billing status in the portal.
  </Accordion>

  <Accordion title="Network error during validation">
    If your machine can't reach `api.lemonsqueezy.com`, CC Commander falls back to Starter tier for that session. It does **not** crash or block your work.

    To validate manually when back online:

    ```bash
    rm ~/.claude/commander/license-cache.json
    ```

    Then open a new session — validation retries automatically.
  </Accordion>

  <Accordion title="Environment variable not picked up">
    Check the variable is exported (not just set):

    ```bash
    echo $CCC_PRO_LICENSE_KEY
    ```

    If empty, re-export it and confirm your shell profile is sourced:

    ```bash
    source ~/.zshrc
    echo $CCC_PRO_LICENSE_KEY
    ```
  </Accordion>
</AccordionGroup>

## Multi-machine use

One Pro license works on up to **3 machines**. Place the same `license.json` (or env var) on each machine. Machines are tracked by Lemon Squeezy — if you exceed 3, new activations are rejected until you deactivate an old machine in the [customer portal](https://app.lemonsqueezy.com/my-orders).
