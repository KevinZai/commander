# Analytics + Non-Coder Agent-Management Scan (2026-07-16)

Scope: what to steal for Commander Cockpit / Mission Control's next slice — skill-run analytics, flows, agent profiles/hierarchy management, workflow suggestions — aimed at **non-coding** Claude Code users. Read-only research, no repo edits. Complements the existing `docs/mission-control-competitive-scan-2026-07-16.md` (task-board/delegation-flow focus) and `docs/mission-control-wave3-agenthq-investigation.md` — this scan is analytics + agent-manager + suggestion-engine focused and does not re-derive their findings.

## TL;DR

- **Analytics space is crowded but MIT-dominant.** 9 of 10 usage/cost dashboards checked (`ccusage`, `claude-hud`, `sniffly`, `token-dashboard`, `phuryn/claude-usage`, `ccgauge`, `Claude-Code-Usage-Monitor`, `Claude-Code-Agent-Monitor`, `sub-agents`) are MIT — code, not just ideas, is legally importable. Only `ccusage/ccusage` itself is unlicensed at the repo level (NOASSERTION) despite 17.2k stars — treat as ideas-only.
- **Skill-level (not just token-level) usage analytics exists and is thin.** `hardness1020/claude-skills-management` (`/skills-analytics-dashboard`) and `AgenticSec/ClaudeCodeUsageDashboard` both log skill/agent/MCP invocations per session — this is the closest prior art to "skill-run analytics," but both ship a separate local web server (Django/Next), not an in-artifact view, and neither is framed for non-coders.
- **Agent-hierarchy/persona management UIs are dev-facing wizards, not visual managers.** No repo found does drag-and-drop or visual org-chart editing of Claude Code subagents; the state of the art is `/agents` (Anthropic, text-wizard, and per July 2026 no longer even opens an interactive creator) and community "sub agent manager" CLIs (`webdevtodayjason/sub-agents`, MIT). CrewAI Studio's canvas (agents/tasks as nodes) is the best non-coder-friendly visual pattern to borrow the *idea* from, but it's a proprietary Enterprise feature — ideas-only.
- **Workflow-suggestion patterns worth stealing come from outside the Claude Code ecosystem** — Raycast AI Extensions' `@mention`-to-invoke-action pattern and Linear Insights' velocity-trend-then-recommend-scope pattern are both **presentation** patterns (trigger → plain-English observation → one-click action), not licensable code; CCC already partially does this via `ccc-suggest`.
- **Gap-check verdict: real but narrower than "nobody's doing this."** Nobody ships "skill-run analytics + visual agent-hierarchy manager + proactive suggestions, rendered inside a Claude artifact, aimed at non-coders" as one product (0 GitHub hits for that combination). But Anthropic itself shipped adjacent official surfaces since ~April–May 2026 (Claude Code Agent View for multi-session monitoring, Live Artifacts for persistent self-refreshing dashboards) that narrow the analytics-UI gap; CCC's defensible slice is the *non-coder framing + skill/persona semantics + suggestion engine*, not "dashboard exists at all."

## Do-not-copy

- **Two repos with unconfirmed/no license** (`AgenticSec/ClaudeCodeUsageDashboard`, `hardness1020/claude-skills-management`) — do not lift code verbatim; re-implement the *mechanism* only, and verify license before any future code reuse.
- **`ccusage/ccusage` code** — 17.2k★ but repo-level license is `NOASSERTION` (no LICENSE file resolved by GitHub's detector) despite being the most-cited tool in the space. Cite it as prior art / ideas-only; do not copy source.
- **Separate local web servers (Django/Next/Express) as the delivery vehicle** — every analytics tool found (`sniffly`, `token-dashboard`, `ccgauge`, `AgenticSec` dashboard, skills-analytics) ships its own `localhost:PORT` app. This is the opposite of CCC's existing no-new-app / in-artifact doctrine (see prior competitive scan §4) — steal the computation, not the server.
- **CrewAI Studio / AutoGen Studio full drag-and-drop canvas** — proprietary, heavyweight, and (per prior scan §4) the closest analog, OpenAI's AgentKit visual builder, was killed 2026-11-30. Visual canvas builders are a validated anti-pattern for this category; a simplified list/card-based agent profile view is the safer non-coder pattern.
- **Sniffly's shareable-transcript feature as-is** — repo has been stale since 2025-08-08 (~11 months); verify it still works against current Claude Code JSONL schema before treating any of its parsing code as current.
