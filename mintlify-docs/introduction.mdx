> **One plugin. 84 skills. Core free forever. Your guided AI PM for every AI coding agent.**

**🖥️ Primary surface: Claude Code Desktop (aka Cowork Desktop).** Install once via Settings → Plugin Marketplace — 84 skills, 22 agents, 30 lifecycle hooks (52 handlers), the Commander HUD mod, and 2 credential-free bundled MCP servers (+16 opt-in via `/ccc-connect`) appear in every session automatically.

> Cowork Desktop and Claude Code Desktop are the same app, two UI modes. The plugin works identically in both. Type `/ccc` to open the hub.

CC Commander is a guided AI PM that helps you master Claude Code — or any Claude-compatible agent IDE — instantly. It's not a skill pack. It reads your project state, scores complexity, routes to the right specialist sub-agent, and gets smarter every session. Built by distilling 200+ community sources into one install, with 22 specialist agent personas, a sub-agent architecture built on Anthropic's Claude Agent SDK pattern, and 30 lifecycle hooks that fire automatically around every session.

## Why Core Free Forever?

<Note>
  **CC Commander is core free forever.** No caps on the plugin. No Stripe. A hosted-infrastructure Pro tier is planned later — all content stays free forever.

  Revenue comes from four sources — none of which require you to pay:
  1. **Consulting** (primary) — Kevin's consulting pipeline. The plugin is a trust engine.
  2. **Affiliate links** (passive) — transparent disclosures in `/ccc-connect` (Supabase, Vercel, Neon, etc.)
  3. **Pro Community** (optional) — a paid Discord/community tier may launch post-beta. The plugin stays free.
  4. **GitHub Sponsors** (optional) — for those who want to contribute directly.

  All 84 plugin skills, 22 sub-agents, 30 lifecycle hooks (52 handlers), 6 plugin workflows, and 2 credential-free bundled MCP servers (+16 opt-in via `/ccc-connect`) are available to everyone, always.
</Note>
