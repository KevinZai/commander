# Social Media Content Strategy

## When to use
Use when you need a social media plan, not individual posts: themes, cadence, and a content calendar. Plan with this template, then draft individual posts from the calendar. Drafts stay drafts; posting or scheduling to a live account needs explicit authorization for each post or batch.

## Template

```
Create a social media content strategy for the product or brand below. Focus on {{primary_platform}}, with supporting content for {{secondary_platforms}}.

**Product/Brand:**
{{what_it_is}}

**Target audience:**
{{who_we_want_to_reach — role, interests, pain points}}

**Primary platform:**
{{X|LinkedIn|Reddit|Instagram|TikTok}}

**Secondary platforms:**
{{list_others}}

**Current presence:**
{{current_following_and_activity — or "starting from zero"}}

**Goals:**
{{awareness|engagement|traffic|conversions — pick 1 or 2}}

Step 1: Content pillars
Define 4 or 5 rotating themes:
1. Educational: tutorials, tips, how-tos.
2. Behind the scenes: process, decisions, challenges.
3. Social proof: user stories, testimonials, metrics, case studies. Use only real, permissioned material.
4. Community: replies, trends, reshares.
5. Product: announcements, features, demos (at most 20% of content).

Step 2: Formats per platform
Starting assumptions to replace with the account's own analytics once data exists:
| Platform | Best formats | Frequency | Posting window |
|---|---|---|---|
| X | Threads, short takes, code snippets | 5-7x/week | audience's morning, midday, early evening |
| LinkedIn | Long-form posts, carousels | 3-4x/week | audience's weekday morning and midday |
| Reddit | Detailed answers, show-and-tell posts | 2-3x/week | varies by community; follow each community's self-promotion rules |

Step 3: Content calendar (2-week sample)
| Day | Platform | Pillar | Topic | Format | Hook |
|---|---|---|---|---|---|
| Mon | X | Educational | ... | Thread | ... |
| Tue | LinkedIn | Behind the scenes | ... | Post | ... |
| Wed | X | Community | ... | Poll | ... |

Step 4: Engagement playbook
- How to respond to comments (tone, response time).
- How to handle negative feedback.
- Which conversations and communities to join.
- Accounts to build relationships with.

Step 5: Metrics
| Metric | Target | Measurement |
|---|---|---|
| Follower growth | {{X}}%/month | Weekly check |
| Engagement rate | {{X}}% | Per post |
| Click-through rate | {{X}}% | Per link post |
| Conversions | {{X}}/month | Attribution tracking |
```

## Tips
- Use `content-strategy` for long-term planning and the `ccc-marketing` router for copy and asset skills for individual posts.
- Consistency beats virality: a steady cadence outperforms sporadic bursts.
- For a recurring calendar review, a Routine (`/schedule`) or `/loop` can re-run the plan; it drafts only and never posts.

## Example

```
Create a social media content strategy for the product or brand below.

**Product/Brand:** An open-source configuration toolkit for AI coding assistants
**Target audience:** Developers who use AI coding assistants
**Primary platform:** X
**Secondary platforms:** Reddit (relevant AI-coding communities), LinkedIn
**Current presence:** starting from zero
**Goals:** Awareness and community engagement
```
