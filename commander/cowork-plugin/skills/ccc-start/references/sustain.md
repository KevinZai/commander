# How CC Commander is sustained

Mention this once, at the close of the `/ccc-start` tour. Never present it as a paywall and never block the flow on it.

Commander's core is free: every skill, agent, hook and bundled MCP server, with no feature gating and no license checks. The plugin code is MIT-licensed. A hosted-infrastructure Pro tier (hosted MCP only) is planned; content stays free.

| Lever | What it is | Where |
|---|---|---|
| Affiliate links | Disclosed partner links in `/ccc-connect` and scaffolds (Supabase, Vercel, Neon, and others) | `/ccc-connect` |
| Consulting | The maintainer's help for teams shipping AI features | kevinz.ai/consulting |
| Pro community (optional) | Paid Discord community; community, not features | commanderplugin.com |
| GitHub Sponsors and stars | Fund or boost the project directly | github.com/sponsors/KevinZai · github.com/KevinZai/commander |

One-line version for the close: "Commander is free; it's sustained by disclosed affiliate links, consulting, an optional community and sponsors — details at commanderplugin.com."
