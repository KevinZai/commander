## Plugin (Recommended)

The fastest path to CC Commander v8.0.0: one command inside any Claude Code session.

<Note>
  **v8.0.0:** Commander routes by model alias — `opus` (Opus 5.5) by default, `fable` (Fable 5.1) for deep work, `sonnet` and `haiku` for fast and bulk work. Six plugin workflows run as `/commander:<name>`. See [What's new in v8](/whats-new-v8).
</Note>

<Steps>
  <Step title="Install the plugin (Claude Code 2.1.292+)">
    ```
    /plugin install commander --marketplace KevinZai/commander
    ```
    This adds the `commander-hub` marketplace and installs the plugin in one step. On older builds, run `/plugin marketplace add KevinZai/commander` first, then `/plugin install commander`.
  </Step>
  <Step title="Restart">
    Fully quit and reopen Claude Code (Cmd+Q on Desktop) so the hooks, agents and the HUD mod load.
  </Step>
  <Step title="Open the command center">
    ```
    /ccc
    ```
    Click a chip. The hub reads your project and recommends the next step.
  </Step>
</Steps>

**On Desktop without a terminal:** Settings → Plugin Marketplace → Add from GitHub → `KevinZai/commander` → install `commander`.

**What you get:** 84 plugin skills, 22 specialist sub-agents, 30 lifecycle hooks × 51 handlers, 6 plugin workflows, the Commander HUD mod, 2 bundled MCP servers. All core free forever — no caps, no feature gating. A hosted-infrastructure Pro tier is planned later — all content stays free forever.

## Advanced / Legacy Install Paths

These paths are for developers who want full CLI control or prefer staying inside the terminal.

<Tabs>
  <Tab title="CLI (npm)">
    You use `claude` in your terminal and want the full interactive CLI binary.

    ```bash
    npm install -g cc-commander
    ```

    <Note>
      The npm package is `cc-commander`; the Claude Code plugin is `commander`. Both are correct — they install separate things.
    </Note>

    Then launch the interactive CLI:

    ```bash
    ccc
    ```

    **What you get:** Full CLI with tmux split mode, daemon, theme switching, cockpit dashboard, and all 467+ skills.

    **Best for:** Developers who live in the terminal.
  </Tab>

  <Tab title="Slash Commands (curl)">
    You don't want a separate CLI binary. Just skills + commands inside Claude Code sessions.

    ```bash
    curl -fsSL https://raw.githubusercontent.com/KevinZai/commander/main/install-remote.sh | bash
    ```

    Then in any Claude Code session:

    ```
    /ccc
    ```

    Full interactive menu appears. Same features, no extra binary.

    **What you get:** All 467+ skills and commands accessible via `/ccc` prefix.

    **Best for:** Developers who prefer staying inside Claude Code.
  </Tab>
</Tabs>

## Your First 60 Seconds

```
1. /plugin install commander --marketplace KevinZai/commander   → Plugin installs
2. /ccc                  → Main menu (84 skills)
3. Pick a skill          → CCC loads the right context
4. Session ends          → CCC auto-saves lessons
5. Next session          → CCC is smarter about your project
```

No YAML. No API keys. No configuration.

## Verify Your Install

```bash
ccc --test
```

Runs 22-point self-verification. All green means you're ready.

```bash
ccc --status
```

Health check JSON — shows gateway, skill count, session state.
