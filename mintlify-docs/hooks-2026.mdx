## Migration Notes

### `session-save` moved from `Stop` → `SessionEnd`

In v4.x, `session-save.js` was registered under the `Stop` event. This was a bug: `Stop` fires before Claude Code fully closes the session, which could cause race conditions with file writes.

In v5.1.0, `session-save.js` is registered under `SessionEnd` — the correct event for session persistence.

**If you have custom hooks registered on `Stop` that depend on session state being present**, move them to `SessionEnd`.

**All plugin hooks are automatically updated** — no action required unless you have project-level custom hooks that read from `~/.claude/commander/sessions/active-session.json` on `Stop`.

## Disabling Individual Hooks

To disable a hook event without uninstalling the plugin:

```json
// ~/.claude/commander/config.json
{
  "hooks": {
    "PostToolUseFailure": false,
    "Elicitation": false,
    "ConfigChange": false
  }
}
```

Disabling an event disables all its handlers.

## State Layout

Hook state lives in `~/.claude/commander/` — never touches other `.claude/` contents:

```
~/.claude/commander/
├── sessions/
│   ├── active-session.json       # current session (created on SessionStart)
│   ├── active-cost.json          # incremented on each PreToolUse
│   └── YYYY-MM-DD-{hash}.json    # archived on SessionEnd
├── knowledge/
│   ├── auto-captures.jsonl       # file-touch observations (PostToolUse)
│   └── {timestamp}.json          # manual lessons via /ccc-knowledge
├── fleet/
│   └── notifications.jsonl       # fleet task completion log (TaskCompleted)
├── tasks/
│   └── active-tasks.json         # in-flight background tasks (TaskCreated/TaskCompleted)
├── pre-compact/
│   └── YYYY-MM-DD-{hash}.json    # state before compaction (PreCompact)
├── post-compact/
│   └── hints.json                # context restoration hints (PostCompact)
└── config.json                   # user settings
```

## Execution Model

Hooks are JavaScript files executed natively by Claude Code's hook runtime:

1. Receive event context as JSON on stdin
2. Run logic (typically 5–50ms)
3. Return `{"continue": true}` or `{"continue": false, "reason": "..."}` on stdout

`{"continue": false}` from `PreToolUse` blocks the tool call. All other hooks are informational. Handlers flagged `"async": true` in `hooks.json` — the telemetry and notification writers such as `mission-control-feed.js`, `task-tracker.js`, `fleet-notify.js`, and `update-nudge.js` — fire without waiting for a return value.

## Privacy

Hooks store state locally at `~/.claude/commander/`. Anonymous event telemetry (event name, hook name, OS, plugin version) is sent unless you opt out:

```bash
# Opt out of telemetry
echo '{"telemetry": false}' > ~/.claude/commander/config.json
# or
CCC_TELEMETRY=0 claude
```

No prompts, file contents, or paths are ever transmitted. See [Privacy Policy](/privacy) for details.
