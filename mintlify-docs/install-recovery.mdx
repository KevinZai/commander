# Install Recovery

## When you need this

- Plugin shows old version after clicking Update
- `/plugin install commander` says installed but no `/ccc` commands appear
- Marketplace UI doesn't reflect the latest release
- Plugin appears installed in `/plugin list` but autocomplete is empty

<Note>
  Before following this guide, run `/ccc-doctor` — it catches ~60% of issues automatically and tells you exactly what's wrong.
</Note>

## The reset sequence

This is the "nuclear cache-fix" sequence. It clears every layer of the plugin cache and forces a clean reinstall.

**Step 1 — Fully quit Desktop (not just close the window)**

```bash
# macOS: Cmd+Q in the app, or via terminal:
osascript -e 'quit app "Claude"'
```

The menu-bar process must exit. A closed window is not enough.

**Step 2 — Clear the plugin cache**

```bash
# Remove every cached executable version (installed_plugins.json's
# installPath points into here — old versions linger with no auto-clean)
rm -rf ~/.claude/plugins/cache/commander-hub/commander

# Remove the Desktop inline copy, if present (bypasses the marketplace
# clone entirely on some installs — a stale one wins silently otherwise)
rm -rf ~/.claude/plugins/data/commander-inline

# Clear the marketplace SOURCE clone (this is the git checkout of
# KevinZai/commander itself — .git lives directly inside this directory)
rm -rf ~/.claude/plugins/marketplaces/commander-hub
```

**Step 3 — Re-add from marketplace and reinstall**

Reopen Claude Code Desktop, then in a new session:

```
/plugin marketplace add KevinZai/commander
/plugin install commander
```

**Step 4 — Enable marketplace auto-update (prevents future stale-cache issues)**

There is no `plugins.autoSync` setting — that shape doesn't exist. The real
mechanism is a per-marketplace `autoUpdate` flag in
`~/.claude/plugins/known_marketplaces.json` (NOT `settings.json`), keyed by
marketplace name:

```bash
node -e "
const fs = require('fs');
const p = require('os').homedir() + '/.claude/plugins/known_marketplaces.json';
const j = JSON.parse(fs.readFileSync(p, 'utf8'));
if (!j['commander-hub']) { console.log('commander-hub not registered yet — add the marketplace first (Step 3), then re-run this'); process.exit(0); }
j['commander-hub'].autoUpdate = true;
fs.writeFileSync(p, JSON.stringify(j, null, 2));
console.log('autoUpdate enabled for commander-hub');
"
```

Back up the file first if you're doing this by hand:
`cp ~/.claude/plugins/known_marketplaces.json ~/.claude/plugins/known_marketplaces.json.backup-$(date +%Y%m%d-%H%M%S)`.
Or just run `/ccc-doctor` — it offers this exact toggle with the backup
already built in.

Even with `autoUpdate: true`, you still need `/plugin update commander` +
a restart to apply a fetched release to your running session — auto-update
only removes the manual `/plugin marketplace update` step.

**Step 5 — Full quit and reopen again**

```bash
osascript -e 'quit app "Claude"'
```

Reopen. The plugin marketplace will sync on startup with autoSync enabled.

## Verify recovery

Run these in a new session after the full reinstall:

```
/ccc
```

You should see the main CC Commander menu with chip pickers for Plan / Build / Review / Ship / Learn / Fleet.

```
/ccc-doctor
```

Should report green on all checks: manifest valid, hooks wired, MCP servers reachable, skill count matches expected (82 skills / 22 agents / 23 hooks × 44 handlers / 2 bundled MCPs). `/ccc-doctor` also now diagnoses stale-install layers — a marketplace clone behind `main`, old `cache/<version>` dirs, stale Desktop inline copies, or an aged catalog cache — and offers to enable marketplace auto-update.

## Orphan `.claude-plugin` bug

**Symptom:** You cloned the repo manually and have a `.claude-plugin/` folder in your project directory. The marketplace installer detects this as a "local plugin" and stops syncing updates from GitHub.

**Fix:** Delete the orphan directory and reinstall from the marketplace:

```bash
# From within the manually cloned directory:
rm -rf .claude-plugin

# Then follow the reset sequence above (Steps 1–5)
```

After this, updates will flow automatically via the marketplace — no manual git pulls needed.
